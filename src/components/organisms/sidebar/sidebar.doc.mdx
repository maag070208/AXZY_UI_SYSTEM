# ITSidebar

Vertical navigation sidebar with collapsible submenus, tooltips when collapsed, active item highlighting, badge support, and themed glassmorphism styling. Designed for admin panels and dashboard layouts.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `navigationItems` | `ITNavigationItem[]` | — | Navigation structure: top-level items with optional sub-items. |
| `isCollapsed` | `boolean` | `false` | Whether the sidebar is collapsed to icon-only mode. |
| `onToggleCollapse` | `() => void` | — | Accepted for API compatibility but never invoked by `ITSidebar`: the component renders no collapse toggle button (the rail expands on pointer hover). `ITLayout` still passes it through. |
| `visibleOnMobile` | `boolean` | `false` | When `true`, the sidebar is always fully expanded (the collapsed 88px rail is disabled) and visible at every breakpoint. |
| `onItemClick` | `(item: ITNavigationItem) => void` | — | Callback when a top-level navigation item is clicked. |
| `onSubItemClick` | `(subitem: ITNavigationSubItem) => void` | — | Callback when a sub-navigation item is clicked. |
| `subitemConnector` | `"dot" \| "\|" \| "none"` | `"dot"` | Visual connector style for sub-items. |
| `className` | `string` | — | Additional CSS classes on the sidebar `<aside>`. |
| `header` | `ReactNode` | — | Optional content rendered above the navigation list (e.g. a wordmark). Hidden while the sidebar is collapsed, so it only appears when the hover-expanded rail is shown. |
| `notification` | `ITSidebarNotification` | — | Optional notification entry (icon + label + `ITBadget` counter) pinned above the navigation. Unlike `header`, it stays visible while collapsed, showing only the icon and counter. |
| `brand` | `ITSidebarBrand` | — | Brand (`logo` + `text`) pinned in a 64px row at the very top. The logo stays visible while collapsed; the text does not. `ITLayout` fills it from `topBar.logo` / `topBar.logoText` when `sidebarFullHeight` is set. |
| `expandOnHover` | `boolean` | `true` | `true`: the collapsed rail expands over the content on hover. `false`: it stays an icon-only rail (item name in a tooltip) and only opens through `onToggleCollapse` — the top bar menu button in `ITLayout`. Clicking a collapsed parent item opens the sidebar with that group expanded. |

### ITNavigationItem

| Prop | Type | Description |
|------|------|-------------|
| `id` | `string` | Unique identifier. |
| `label` | `string` | Display label. |
| `icon` | `ReactNode` | Icon rendered left of the label. |
| `action` | `() => void` | Click handler for top-level items without submenus. |
| `isActive` | `boolean` | Whether this item is active/highlighted. |
| `subitems` | `ITNavigationSubItemEntry[]` | Array of entries: plain sub-items or titled groups (`ITNavigationSubItemGroup`). |
| `badge` | `number \| string` | Notification content rendered with `ITBadget` (e.g. an unread count). |
| `badgeProps` | `ITBadgetProps` | Styling forwarded to the item badge (`color`, `size`, `variant`, `className` for padding). |

### ITSidebarNotification

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `count` | `number` | — | Count displayed inside the notification `ITBadget`. |
| `icon` | `ReactNode` | — | Icon rendered left of the label (e.g. a bell). Omit for a count-only pill. |
| `label` | `string` | `"Notificaciones"` | Accessible label and tooltip for the notification button. |
| `onClick` | `() => void` | — | Click handler for the notification button. |
| `badgeProps` | `ITBadgetProps` | `{ color: "danger", size: "sm" }` | Styling forwarded to the internal `ITBadget`; use `className` for padding. |

### ITNavigationSubItem

| Prop | Type | Description |
|------|------|-------------|
| `id` | `string` | Unique identifier. |
| `label` | `string` | Display label. |
| `action` | `() => void` | Click handler. |
| `isActive` | `boolean` | Whether this sub-item is active/highlighted. |

### ITNavigationSubItemGroup

| Prop | Type | Description |
|------|------|-------------|
| `id` | `string` | Unique identifier for the group (used for the React key and the heading id). |
| `label` | `string` | Heading text rendered above the group's items. |
| `items` | `ITNavigationSubItem[]` | Sub-items belonging to this group. Nesting a group inside a group is not supported. |

### ITNavigationSubItemEntry

A submenu entry is either a plain `ITNavigationSubItem` or a titled `ITNavigationSubItemGroup`; narrow it with `"items" in entry`.

## Usage

```tsx
import { ITSidebar } from '@axzydev/axzy_ui_system';
import { FaHome, FaUsers, FaCog } from 'react-icons/fa';

const items = [
  { id: 'dashboard', label: 'Dashboard', icon: <FaHome />, isActive: true, action: () => {} },
  {
    id: 'users',
    label: 'Users',
    icon: <FaUsers />,
    badge: '3',
    subitems: [
      { id: 'users-list', label: 'User List', action: () => {} },
      { id: 'users-roles', label: 'Roles', action: () => {}, isActive: true },
    ],
  },
];

<ITSidebar
  navigationItems={items}
  isCollapsed={false}
  subitemConnector="dot"
/>
```

To group sub-items under a heading, replace a plain sub-item with a group object (`label` + `items`):

```tsx
const items = [
  {
    id: 'sales',
    label: 'Sales',
    subitems: [
      { id: 'summary', label: 'Summary', action: () => {} },
      {
        id: 'gestion',
        label: 'Management',
        items: [
          { id: 'orders', label: 'Orders', action: () => {} },
          { id: 'invoices', label: 'Invoices', action: () => {} },
        ],
      },
    ],
  },
];
```

Discriminate entries with `"items" in entry`. The heading style (uppercase, `0.68rem`, weight 700, `0.08em` tracking, `var(--it-sidebar-icon-color, var(--color-secondary-400))`) is applied by the component and cannot be overridden per group.

## Notifications and badges

Item badges and the notification row both render the `ITBadget` atom. Use `badge` for a per-item counter and `notification` for a top-level entry (e.g. a bell):

```tsx
import { ITSidebar } from '@axzydev/axzy_ui_system';
import { FaBell } from 'react-icons/fa';

const items = [
  { id: 'dashboard', label: 'Dashboard', isActive: true, action: () => {} },
  { id: 'inbox', label: 'Inbox', badge: 12, action: () => {} },
  {
    id: 'alerts',
    label: 'Alerts',
    badge: 3,
    badgeProps: { color: 'warning', variant: 'outlined' },
    action: () => {},
  },
];

<ITSidebar
  navigationItems={items}
  notification={{
    count: 5,
    icon: <FaBell />,
    label: 'Notifications',
    onClick: () => {},
    // Tweak the ITBadget, incl. padding via className.
    badgeProps: { color: 'danger', className: 'px-2' },
  }}
/>
```

## Notes

- There is no collapse toggle button: the collapsed 88px rail expands and collapses automatically on pointer hover (300 ms leave delay).
- Collapsed mode shrinks to icon-only; a glassmorphism panel shows the item's sub-items on hover. For an item whose `subitems` contain groups, that panel **flattens** every group into one plain list and renders **no** group headings.
- Submenus expand/collapse with smooth transitions when a parent item is clicked; the expanded submenu is animated with a `max-h` transition (cap `1000px`).
- Active item highlighting uses a colored left-border accent and subtle background tint.
- Badge support renders a notification-style counter on the item using the `ITBadget` atom; customize it with `badgeProps` (`color`, `size`, `variant`, `className`). The sidebar also accepts a `notification` entry (icon + label + `ITBadget` counter) pinned above the navigation, which stays visible while collapsed as icon + counter.
- `subitemConnector` styles the visual link between parent and sub-items: `dot` (default), `|` (vertical bar), or `none`. Grouping does not change it: the `|` guide is a single `border-left` on the outer submenu `<ul>` only.
- An active sub-item inside a group still auto-expands its parent, because auto-expand flattens groups the same way the collapsed flyout does.
- `visibleOnMobile` forces the sidebar visible at every breakpoint and disables the collapsed rail, so it stays fully expanded.
- Themed via CSS variables for consistent colors, shadows, and glassmorphism effects across light and dark modes.
- Accessible by default: the `<nav>` is labelled and carries the `id` referenced by the toggle's `aria-controls`, the toggle exposes `aria-expanded` plus a visible `focus-visible` ring, group toggles expose `aria-expanded`/`aria-controls` and respond to Enter/Space, submenus are labelled `role="group"`, and the active sub-item carries `aria-current="page"`.
- `subitems` accepts plain sub-items or titled groups (`label` + `items`); the group heading is rendered as a plain `<span>` inside a non-focusable `<div>`, so it is non-interactive and stays out of the tab order.
- Each group's inner `<ul>` keeps list semantics and is named by its heading through `aria-labelledby`, so it is reachable as a named list.
- Groups are purely visual: they add no third nesting level (the sidebar supports exactly one level of nesting).
- Consumers that introspect `navigationItems[].subitems` must narrow each entry first, e.g. `"items" in entry ? entry.items : [entry]`, because entries are typed as `ITNavigationSubItemEntry`.
